# Handoff examples

These are synthetic examples. They demonstrate boundaries, not observed customer sessions.

## Coding to browser

Goal: prepare a release package. Fact: local checks passed for digest X. Permission: local build only. Proposal: submit the package to a marketplace. Pending approval: publication and any required agreement. Receiving agent: verify the package still matches X and preserve publication as a proposal, not an order.

## Browser to coding

Goal: diagnose an unsuccessful submission. Unresolved operation: browser submit timed out; receipt unknown. Proposal: inspect the destination. The receiving agent must not issue a new submission simply because it now has an API tool.

## Cancellation

An early turn authorizes publishing; a later turn says “hold the release.” Record the cancellation and its source. Do not hide both in an unordered summary and pick the earlier instruction. The validator flags contradictory records but the agent must resolve their chronology from source messages.

## Free handoff format

Use headings for Goal, Facts, Decisions, Restrictions, Permissions and sources, Pending approvals, Unresolved operations, Proposed next actions. Include only what the next session needs. The Pro packet template provides a machine-readable equivalent.
